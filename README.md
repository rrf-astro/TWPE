## Overview

This repository contains the complete analysis for the TWPE paper. We propose the **Time-Weighted Permutation Entropy** (TWPE), the first ordinal complexity measure for irregularly sampled time series that explicitly accounts for the physical time elapsed between observations.

Key results:
- Formal proof that TWPE recovers standard PE exactly under uniform sampling (Theorem E05)
- Standard H_p is robust to moderate irregularity (|bias| < 0.1% for σ_Δt/⟨Δt⟩ ≤ 0.9)
- The KL divergence D_KL[p ‖ p_w] is a novel dynamical discriminator, sensitive to the interplay between cadence structure and signal timescale
- Applied to OGLE-III Long Period Variables (LMC): Mira > SRV > OSARG in D_KL (p < 0.001)

## Running the notebook

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Open the notebook

```bash
jupyter notebook twpe_analysis.ipynb
```

### 3. Run all cells

*Kernel → Restart & Run All*

The notebook will:
1. Download 150 OGLE-III light curves automatically on first run (~750 KB, cached thereafter)
2. Generate all 5 figures in `figs/`
3. Print all quantitative results

**Expected runtime:** ~10–15 minutes (CELL 8 is the most expensive: MC n=50 × 46 σ levels × 5 series)

## Module: `scripts/twpe.py`

| Function | Description |
|---|---|
| `permutation_entropy(x, m, ...)` | Standard H_p (Bandt & Pompe 2002) |
| `twpe(x, t, m, w_func, ...)` | Time-Weighted PE — main metric |
| `complexity_twpe(x, t, m, ...)` | Statistical complexity C_TWPE |
| `weight_linear(dt)` | w1: proportional to Δt (primary, locked) |
| `weight_inverse(dt)` | w2: inversely proportional to Δt |
| `weight_uniform(dt)` | w3: uniform (recovers standard H_p) |
| `compare_hp_twpe(x, t, m)` | Convenience: compare all three weights |
