# Time-Weighted Permutation Entropy (TWPE)

**Paper:** *Time-Weighted Permutation Entropy: ordinal analysis of unevenly sampled time series*
**Authors:** R. R. Ferreira, A. M. S. Borin (Federal Institute of Triângulo Mineiro, IFTM, Uberaba-MG, Brazil)
**Target journal:** TBD
**Status:** In preparation

---

## Overview

This repository contains the complete analysis for the TWPE paper. We propose the **Time-Weighted Permutation Entropy** (TWPE), an extension of permutation entropy to irregularly sampled time series in which each ordinal pattern is weighted by the time interval to the next observation.

Main results (see the paper for the scope and limits of each one):
- TWPE reduces to standard PE under uniform sampling (a consistency property, checked analytically and numerically)
- In synthetic tests with Gaussian jitter (σ_Δt/⟨Δt⟩ ≤ 0.9, m = 4), the mean difference between H_TWPE and H_p stays below 0.2% for four of the five processes tested (up to 0.6% for the Lorenz series, which also shows a larger scatter among realisations)
- The symmetrised KL divergence D_KL[p ‖ p_w] is examined as a candidate diagnostic of the interaction between cadence and signal
- In 150 OGLE-III long-period variables (LMC, I band, 50 per class), D_KL is larger for Miras than for SRVs and for SRVs than for OSARGs (Holm-adjusted p < 0.001 for the three pairs). The dependence on the pulsation period could not be separated from those on amplitude and signal-to-noise ratio (see `supplementary/`)

## Repository structure

The main analysis is a **single, self-contained notebook**: all functions are defined in its Cell 1, and no external scripts or modules are needed. A few supplementary analyses quoted in the paper are kept as separate scripts in `supplementary/`; they do not change the notebook or its numbers.

```
TWPE/
├── twpe_analysis.ipynb          # Main notebook — run this (self-contained)
├── data/
│   └── observed/
│       └── ogle3_lpv/
│           ├── ident.dat        # OGLE-III LPV catalog (Soszyński et al. 2009)
│           ├── Miras.dat        # Mira parameters
│           ├── SRVs.dat         # SRV parameters
│           └── OSARGs.dat       # OSARG parameters (used only by the supplementary scripts)
│           # phot_I/ is downloaded automatically by the notebook
├── supplementary/               # Supplementary analyses (scripts); see its README
│   └── results/                 # Reference outputs (logs, tables, figures) of those scripts
├── figs/                        # Figures (generated by the notebook)
├── requirements.txt
├── LICENSE
└── README.md
```

## Running the notebook

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Open the notebook

```bash
jupyter notebook twpe_analysis.ipynb
```

### 3. Run all cells

*Kernel → Restart & Run All*

The notebook will:
1. Run a short self-test of the TWPE core (Cell 1b)
2. Download 150 OGLE-III light curves automatically on first run (~750 KB, cached thereafter)
3. Generate all 5 figures in `figs/`
4. Print all quantitative results

Cell 18 (supplementary recomputation) must be run after Cell 14, since it reuses its results.

**Expected runtime:** about 4–6 minutes on a laptop (3 min 58 s measured with the light curves already cached; 6 min 11 s in a fresh clone, including the downloads). CELL 8 is the most expensive: MC n=50 × 46 σ levels × 5 series.

## Data

Light curves are downloaded automatically from the OGLE-III public FTP server:
`https://ftp.astrouw.edu.pl/ogle/ogle3/OIII-CVS/lmc/lpv/phot/I/`

The catalog files (`ident.dat`, `Miras.dat`, `SRVs.dat`, `OSARGs.dat`) are included in this repository.

## Functions (defined in Cell 1 of the notebook)

| Function | Description |
|---|---|
| `permutation_entropy(x, m, ...)` | Standard H_p (Bandt & Pompe 2002) |
| `twpe(x, t, m, w_func, ...)` | Time-Weighted PE — main metric |
| `complexity_twpe(x, t, m, ...)` | Statistical complexity C_TWPE |
| `weight_linear(dt)` | w1: proportional to Δt (primary) |
| `weight_inverse(dt)` | w2: inversely proportional to Δt |
| `weight_uniform(dt)` | w3: uniform (recovers standard H_p) |
| `kl_sym(p, p_w)` | Symmetrised KL divergence D_KL[p ‖ p_w] |
